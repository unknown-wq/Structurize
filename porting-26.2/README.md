# Инструкции для порта на Minecraft 26.2

Документы для кодинг-агентов, портирующих мод на Fabric / Minecraft 26.2. Скопированы
как есть из четырёх репозиториев, где порт уже доведён до зелёного выделенного сервера:
`Fabric-LuckyTNTMod`, `simple-planes`, `LostCities`, `desolation`.

Читать в этом порядке.

| Файл | Что это |
|---|---|
| **`PORT-ANY-MOD-26.2.md`** | **Начинать отсюда.** Универсальный план: выбор маршрута, окружение, замороженные контракты, разбиение работы между агентами, правило деградации, приёмка, готовые промпты оркестратору и агентам. |
| `NEOFORGE-TO-FABRIC-26.2.md` | Ближайший аналог задачи MineColonies: NeoForge 1.21.1 → Fabric 26.2 одним хопом. Находки сборки и рантайма, уроки параллельной работы агентов. |
| `NOTES-A.md` | Пофайловые рецепты: entrypoint, регистрация, меню/контейнеры, рецепты, reload-листенеры, JSON данных. |
| `NOTES-B.md` | Сущности, synched data, `ValueInput`/`ValueOutput`, апгрейды, сеть. |
| `NOTES-C.md` | Клиент: инициализация, рендереры и render states, модели, экраны, звуки, миксины. |
| `PORT-MOD-26.2.md` | Проверенная таблица ренеймов Yarn→26.2 по областям + экономика токенов. Полезна и для Forge-исходника: правая колонка — это и есть имена 26.2. |
| `PORT-CHEATSHEET.md` | Готовые исправления повторяющихся ошибок компиляции, переживших массовые ренеймы. |
| `PORTING-GUIDE-26.2.md` | Технический референс: почему наивный порт ломается, пер-версионный hit-list ломок 1.21.2 → 26.2, матрица тулчейна, промпт веб-перепроверки. |
| `port-rename*.sh` | Рабочие скрипты массовых ренеймов (писались под Yarn-источник — для NeoForge нужен свой, короче; как его писать — §7 плана). |
| `port-resolve-imports.py` | **Полезен здесь как есть.** Проходит по всем `import net.minecraft.*`, ищет класс в `/opt/mc-src`; если он найден ровно в одном пакете — переписывает импорт на новый путь. Чинит все классы, которые просто переехали, без единой ручной правки. Мода не касается: неоднозначные и ненайденные оставляет агенту. Требует готового `/opt/mc-src`. |
| `fix-recipes.py` | Рецепты JSON в формат 26.2: ингредиенты становятся плоскими строками (`{"item":"X"}` → `"X"`, `{"tag":"X"}` → `"#X"`) в `key`, `ingredients` и `ingredient`. Под MineColonies нужно проверить пути и Forge-теги. |
| `port-rename6.pl` | Мелкие добивки, из которых две универсальные: `.random` → `.getRandom()` и `.isClientSide` → `.isClientSide()` (в 26.2 оба поля `Level` приватные — это ошибка из `NEOFORGE-TO-FABRIC-26.2.md`). |

Три факта, которые чаще всего теряются:

1. Цель — **`26.2`**, а не «1.26.2»: с 2026 версии в схеме `year.drop.hotfix`.
2. С 26.1 игра **необфусцирована**: строки `mappings` в Gradle нет, Java **25**.
   NeoForge уже на именах Mojang, поэтому миграции имён в этом порте не будет —
   ломаются только сами API.
3. `ResourceLocation` в 26.2 **не существует**: класс называется
   `net.minecraft.resources.Identifier`, фабрика — `Identifier.fromNamespaceAndPath(...)`.
   Это не yarn-имя, Mojang принял его после расобфускации.

Тренировочные данные модели по диапазону 1.21.2 → 26.2 устарели. Единственный источник
истины — декомпилированные исходники игры в `/opt/mc-src` и уже портированные 26.2-моды
на диске. Если они противоречат этим документам — правы они.
